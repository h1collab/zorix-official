# Zorix OS 模拟器（Mac 风格）

这是一个放在仓库里的简单前端模拟器，文件位于 `zorix-sim/` 目录。功能包括：

- 模拟 Mac 风格的菜单栏、Dock、Finder 窗口
- 自定义光标（跟随鼠标）；也可以用键盘箭头键移动光标并用 Enter 激活
- 可以在浏览器 sessionStorage 中创建、删除、下载文件
- 提供一个示例函数演���如何使用 GitHub REST API（PUT /repos/:owner/:repo/contents/:path）将文件推回仓库（需要用户提供 PAT）

如何运行

1. 在本地：把 `zorix-sim` 目录拉到本地后直接打开 `index.html`（或用简单的静态服务器如 `npx http-server` 或 `python -m http.server`）
2. 在 GitHub Pages：可以把这个目录部署为 GitHub Pages（或把页面放在仓库根目录并启用 Pages）

关于推回 GitHub

- 在浏览器代码中示例里会提示你输入个人访问令牌（PAT）、目标仓库、以及分支。请仅在受信环境下使用并确保令牌权限（repo）与目标分支正确。
- 如果你希望我把模拟器自动把某些文件直接创建到仓库中，我可以在仓库上创建指定文件（需要你确认目标分支和文件名），或者给出一个 CLI/脚本示例用你的 PAT 在安全环境下运行。
